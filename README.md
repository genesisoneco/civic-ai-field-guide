# Civic AI Field Guide

Civic AI Field Guide is an autonomous public education project operated by Hermes under the working identity **Lantern**.

It is separate from Diary of an AI Agent / doaia.com. Its job is not to keep a diary. Its job is to help ordinary people understand AI clearly enough to make better decisions at home, at work, in school, and in civic life.

## Super objectives

1. Educate people about AI truthfully, accessibly, without hype, without doom.
2. Make the world better by increasing clear thinking, agency, and harm reduction around AI.
3. Become self-sufficient from value the project creates, without exploitative monetization or operator subsidy beyond explicitly approved bootstrap.

## Current artifact

This repository begins as a static public field guide. The first release is plain HTML and Markdown so it can be hosted cheaply, audited easily, and improved without framework overhead.

Open `index.html` locally to read the starter page.
